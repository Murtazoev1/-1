# Шпион — party-игра (v2, «слово + тема»)

Полная переработка исходного `spy-party-game-FINAL`: механика заменена с
«локация + роль» на «слово + тема» (см. `promt_igra_shpion_v2.md`), все
модальные окна закрываются тремя способами (крестик / фон / Escape — см.
`promt_ispravlenie_bagov.md`), добавлены недостающие экраны и адаптив под
телефон и планшет.

## Запуск

```bash
npm install
npm run dev
```

Откроется на `http://localhost:5173`. Соберите продакшен-версию командой
`npm run build` — папку `dist/` можно упаковать в Capacitor / TWA для
публикации в Google Play.

## Что реализовано

- 11 экранов: сплэш, меню, игроки, темы, настройки, подготовка к раунду,
  раздача слов (flip-карточка), таймер, голосование/изгнание, «Угадай слово»,
  результаты.
- Игроки видят **слово + подпись темы**; шпион — ничего / только тему / тему
  и 3 слова-подсказки (настраивается).
- Изгнание: если изгнан не шпион — баннер-уведомление, раунд продолжается
  (+60 сек, если время уже вышло), а не сбрасывается.
- Кнопка «Я — шпион» → полный список слов темы → подтверждение → результат.
- 30 тем × 15–20 слов, свой акцентный цвет на тему.
- Настройки: число шпионов, время раунда, сложность шпиона, вкл/выкл
  «Я — шпион», звук, вибрация, тёмная/светлая тема, язык (RU/EN).
- Все всплывающие окна закрываются крестиком, кликом по фону и Escape.
- Адаптив: брейкпоинты под 360 / 390–430 / 768 / 1024 / 1280px, отдельная
  раскладка для планшета (2–4 колонки, центрированные модалки), альбомная
  ориентация учтена, safe-area отступы, `viewport-fit=cover`.
- Данные (игроки/темы/настройки/статистика побед) сохраняются в
  `localStorage` между сессиями.
- `manifest.json` подготовлен для PWA/Capacitor.

## Структура

```
index.html
manifest.json
package.json
vite.config.js
src/
  App.jsx     — всё приложение: данные, стор, экраны, стили
  main.jsx    — точка входа React
```

Всё приложение сознательно оставлено в одном `App.jsx` (компактнее для
ревью и правок), но внутри он чётко разбит на секции: DATA → I18N → UTILS →
STATE → UI ATOMS → SCREENS → STYLES → ROOT APP — при желании легко разнести
по папкам `screens/`, `components/`, `store/`, `data/`.
